# Regime State Compression Study — 2026-09-17

## Status

Observation-only research. This study is downstream of `research/multidimensional-regimes-20260917` and inherits its causal walk-forward data construction.

No Core v1 runtime, regime thresholds, ordering, weights, strategy logic, orders, execution, NAV, exposure, or portfolio behavior is authorized to change.

## Motivation

The multidimensional-regime study showed that a compact continuous representation (`strength`, `log_atr`) retained substantially more forward-variance information than the current categorical Core regime label, while naive combinatorial states became sparse and generic six-cluster K-means underperformed Core.

The next question is therefore not "how many regimes should exist?" It is:

> What is the smallest stable representation of observable market state that preserves useful forward-distribution information without fragmenting into sparse states?

## Research questions

1. How much predictive information is retained when the five-dimensional observable state vector is compressed to 1, 2, 3, 4, or 5 orthogonal components fitted on training data only?
2. If categorical states are desired, how many training-fitted clusters are required to approach the continuous information ceiling while maintaining adequate occupancy and temporal persistence?
3. Does compact state information add incremental forward-distribution information conditional on the existing Core regime label?
4. Within high-occupancy Core labels, especially `VOL_COMPRESSION`, are there stable compact-state substructures with distinct forward distributions?

## Frozen inputs

Use the same panel construction, assets, timeframes, daily UTC snapshots, causal maturity boundary, yearly 2020-2025 evaluation folds, five state features, and forward targets used by `research.multidimensional_regimes`.

State features:

- `strength`
- `momentum`
- `log_atr`
- `atr_accel`
- `efficiency`

Forward targets:

- `future_return`
- `log_variance`
- `downside`

No future target may enter feature scaling, dimensionality reduction, clustering, state assignment, or representative-state construction.

## Candidate representations

### Continuous compression

Fit `StandardScaler` and PCA on training features only. Evaluate cumulative component sets PCA-1 through PCA-5 using the same Ridge decoder and the same matured-outcome training rows as the prior study.

PCA is used here as an information-retention probe, not as a claim that the market is linearly generated by latent factors.

### Compact categorical states

On the training-only standardized PCA coordinates, fit deterministic K-means candidates for K in `{2, 3, 4, 6, 8, 10, 12}` using fixed seed 1729 and single-thread numerical execution.

Each fold-local cluster identity is local to that fold. Cluster labels must not be treated as semantically stable across years, assets, or timeframes.

Use the same shrinkage state decoder and `MIN_SUPPORT` behavior as the predecessor study.

### Core-conditional incremental models

For every target, compare:

- constant baseline;
- Core categorical state forecast;
- compact continuous representation;
- Core one-hot + compact continuous representation.

The incremental quantity of interest is out-of-sample loss reduction of `Core + compact` relative to `Core` alone. This is descriptive research, not a promotion gate.

## Diagnostics

For each fold and representation record:

- out-of-sample MSE and skill versus constant;
- incremental skill versus Core where applicable;
- state occupancy and training support;
- largest-state fraction;
- fraction of evaluation observations assigned to sparse/unseen states;
- transition self-probability;
- episode-length distribution;
- cluster centers in scaled/PCA coordinates;
- explained variance ratio for PCA;
- target distribution summaries by state;
- Core x compact-state cross-tabulation.

## Interpretation constraints

A candidate categorical representation is not considered useful merely because its average score improves. Review score, occupancy, persistence, sparsity, and cross-fold consistency together.

A representation that improves only `log_variance` may be a volatility-state model rather than a general regime representation. Report this explicitly rather than relabeling it as a broad regime improvement.

No trading PnL, strategy returns, Sharpe, CAGR, Calmar, order simulation, sizing, or portfolio optimization is part of this study.
